# Contributing

signalbox is developed in a yardr yard. An issue or a pull request you open
on GitHub becomes a bead there.

## An issue

Open an issue on
[yardr-dev/signalbox](https://github.com/yardr-dev/signalbox/issues). Say
what you saw, where, and how to see it again.

A maintainer reads it before anyone builds from it. The label `accepted`
means the maintainer wants it, and it joins the project's own work.
Closing the issue drops it.

## A pull request

Open a pull request against `main`. The template has three lines. They are
what changed, why, and how you tested it.

A maintainer looks at every pull request before any of its code is run. The
label `accepted` means that look is done, and the pull request may be read.
A maintainer merges on GitHub, or closes the pull request.

## The yard's bot

A bot of the yard may triage an issue or a pull request, add a label, and
comment. A comment it leaves is marked as from an agent. A maintainer still
decides. The label `accepted` is theirs, and so is merging or closing.
